# argocd

Helm wrapper chart for [Argo CD](https://argo-cd.readthedocs.io) (`argo-cd 7.8.2`),
the GitOps controller that manages every other Helm chart in this repo
(see `../../apps/` and `../../root.yaml`).

## What it does

- Deploys Argo CD server, repo-server, application-controller, redis, dex,
  and notifications-controller into the `argocd` namespace.
- Exposes the Argo CD UI/API at `http://argocd.localhost:9999` via ingress
  (plain HTTP - `server.insecure: true` / `--insecure`, since this local
  kind cluster's nginx ingress doesn't terminate TLS).

## Bootstrapping the rest of the stack

After this chart is installed (`make install-argocd`), apply the root
"app of apps" once to have Argo CD start managing every other chart:

```bash
kubectl apply -f root.yaml
```

See `../../GITOPS.md` for how each chart's Application is
structured and how to sync/pause/delete them individually.

## Access

| URL | Credentials |
|---|---|
| http://argocd.localhost:9999 | `admin` / (see below) |

Get the initial admin password (auto-generated by the chart):
```bash
kubectl -n argocd get secret argocd-initial-admin-secret \
  -o jsonpath='{.data.password}' | base64 -d
```
